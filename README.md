# 复利与定投计算器

适合 Python 初学者的金融数学练习：输入本金、假设名义年利率、年数和每月定投，计算累计投入、期末金额及收益。

## 第一版目标

- 在终端运行，不需要安装第三方库。
- 用一个函数理解参数、循环和 return。
- 用输入、输出及条件判断完成一个可使用的小程序。
- 用可以手算的例子检验结果。

## 运行

在 VS Code 中打开包含这些文件的文件夹，打开终端：

python main.py

## 计算约定

本项目把输入利率定义为**名义年利率、按月复利**：6% 对应月利率 0.5%，有效年利率为 `(1 + 0.06 / 12) ** 12 - 1`，约 6.17%。如果手里的是有效年利率，换算月利率应使用 `(1 + 年利率) ** (1 / 12) - 1`，不能混用。

每个月先计息，再在月底投入：

```python
balance = balance * (1 + monthly_rate) + monthly_contribution
```

- 本金在开始时投入；首笔月定投在第一个月底投入。
- 年数为非负整数；0 年返回初始本金，不发生定投。
- 本金和定投金额不能为负；本练习限制名义年利率大于 -100%。
- 允许负利率，计算出的收益也可能为负。
- 函数接收小数利率 `0.06`；界面接收百分数 `6`，并除以 100。
- 计算过程不逐月舍入，只在显示时保留两位小数。
- 固定利率只是数学假设；暂不包含费用、税费、通胀和市场波动。
- 使用浮点数，适合学习演示，不是银行逐分记账程序。
